# SpotiPlayGram

[![README на английском](https://img.shields.io/badge/README-EN-blue)](README.md)

**SpotiPlayGram** — это Python-приложение, которое отображает текущий трек Spotify в Telegram-канале в реальном времени. Оно автоматически обновляет в канале обложку альбома и информацию о треке, а также опционально добавляет ссылку на текст песни на Genius.

---

## 💡 Идея

Основная идея приложения — **добавить созданный канал в свой Telegram-профиль** (Настройки → Изменить профиль → Личный канал). При воспроизведении музыки в Spotify название канала автоматически меняется на **«Исполнитель – Название трека»**, а в сообщении отображается подпись **«Now Playing on Spotify»**.

Это создаёт эффект **полноценного статуса воспроизведения Spotify** прямо в вашем Telegram-профиле — другие пользователи видят, что вы сейчас слушаете, как в классическом Spotify-статусе.

## ✨ Возможности

### 🎵 Интеграция со Spotify

- Отслеживание текущего трека в реальном времени
- Отображение имени исполнителя, названия трека, альбома и даты релиза
- Автоматическая загрузка и отображение обложки альбома

### 📢 Обновление Telegram-канала

- Обновление сообщений канала информацией о треке и обложкой альбома
- Динамическое изменение названия канала на текущий трек
- Обновление фото профиля канала обложкой альбома
- Автоматическое удаление всех сообщений, кроме первого сообщения канала и двух основных сообщений статуса

### 📝 Интеграция с Genius

- Автоматический поиск ссылки на текст песни на Genius
- Продвинутый алгоритм нечёткого сопоставления для точных результатов

### 🤖 Выбор с помощью Mistral AI

- Использование Mistral AI для интеллектуального выбора лучшей ссылки
- Поддержка нескольких AI-моделей с автоматическим переключением
- Настраиваемая приоритетная цепочка моделей

### 🎛️ Панель управления ботом

- Telegram-бот для администрирования
- Включение/выключение статуса воспроизведения
- Управление настройками Genius (паттерны версий и паттерны feat)
- Настройка моделей Mistral AI прямо из Telegram

### ⚙️ Дополнительные возможности

- Кроссплатформенная поддержка (Windows, Linux, macOS, FreeBSD)
- Автоматическое создание виртуального окружения
- Опциональная ежедневная проверка обновлений зависимостей (в 00:00 UTC)
- Отдельные скрипты для включения и отключения автозапуска
- Защита от одновременного запуска на нескольких устройствах

- Python 3.10 или выше
- Аккаунт разработчика Spotify

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/xsfeelyou/SpotiPlayGram.git
cd SpotiPlayGram
```

### 2. Настройка переменных окружения

Скопируйте файл `.env-example` в `.env` и укажите ваши учётные данные:

```bash
# Windows
copy .env-example .env

# Linux, macOS, FreeBSD
cp .env-example .env
```

```env
# Spotify API
SPOTIFY_CLIENT_ID=ваш_spotify_client_id
SPOTIFY_CLIENT_SECRET=ваш_spotify_client_secret
SPOTIFY_REDIRECT_URI=http://127.0.0.1:47474/callback
SPOTIFY_LANGUAGE=RU  # Язык для запросов к Spotify API
SPOTIFY_REQUEST_TIMEOUT=5  # Таймаут запросов к Spotify API в секундах

# Telegram API
TG_API_ID=ваш_telegram_api_id
TG_API_HASH=ваш_telegram_api_hash
TG_BOT_TOKEN=ваш_bot_token

# Telegram IDs
TG_CHANNEL_ID=1234567890
TG_ADMIN_USER_ID=ваш_user_id

# ID сообщений в канале
TG_MEDIA_MESSAGE_ID=2
TG_TEXT_MESSAGE_ID=3

# Genius API (опционально)
GENIUS_ACCESS_TOKEN=ваш_genius_token
ENABLE_GENIUS=True  # Включить поиск текстов песен через Genius API
GENIUS_DETAILED_LOG=False  # Подробное логирование работы Genius

# Mistral AI (опционально)
MISTRAL_API_KEY=ваш_mistral_api_key
ENABLE_MISTRAL=True  # Включить Mistral AI для точного выбора URL текстов песен
MISTRAL_MODEL=codestral-latest  # Модель Mistral AI (по умолчанию)

# Повторные попытки авторизации
AUTH_RETRY_MAX_RETRIES=2  # Максимальное количество попыток авторизации
AUTH_RETRY_DELAY_BASE=1  # Базовая задержка между попытками авторизации в секундах

# Автообновление зависимостей
ENABLE_DEP_UPDATES=False  # Автоматическое обновление зависимостей при запуске

# Интервал обновления в секундах
UPDATE_INTERVAL=1  # Интервал опроса Spotify API в секундах
```

## 🔧 Настройка

### 🎵 Настройка Spotify

1. Перейдите на [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)
2. Создайте новое приложение
3. В настройках приложения добавьте Redirect URI: `http://127.0.0.1:47474/callback`
4. Скопируйте Client ID и Client Secret в `.env`

**Примечание об авторизации:** Spotify использует **авторизацию через OAuth 2.0** — при первом запуске откроется браузер для входа в ваш аккаунт. **Авторизация через SSH невозможна**, так как нет доступа к графическому интерфейсу. Первую авторизацию необходимо выполнить на компьютере с графическим интерфейсом (Windows, Linux с GUI, macOS или FreeBSD), а затем перенести файлы сессии на целевое устройство.

**Примечание о языке:** Выберите правильное значение для `SPOTIFY_LANGUAGE` в `.env` — оно должно соответствовать языку вашего Spotify-приложения. Этот параметр влияет на то, как отображаются имена исполнителей и названия треков в вашем Telegram-канале. Например, если имя исполнителя записано нелатинскими буквами (кириллица, хангыль, иероглифы и т. д.), то при `SPOTIFY_LANGUAGE=EN` имя может отображаться латиницей, а при `SPOTIFY_LANGUAGE=RU` (или соответствующем коде языка) — в оригинальной письменности.

**Примечание об ограничениях:** Эндпоинт Spotify Web API для получения статуса воспроизведения может потребовать Premium-аккаунт (зависит от ограничений/политики Spotify).

### 📢 Настройка Telegram

1. Перейдите на [my.telegram.org](https://my.telegram.org)
2. Создайте новое приложение
3. Скопируйте `api_id` и `api_hash` в `.env`
4. Создайте бота через [@BotFather](https://t.me/BotFather)
5. Скопируйте токен бота в `.env`

#### Подготовка Telegram-канала

1. Создайте **публичный** Telegram-канал (публичный канал необходим для добавления в профиль)
2. Добавьте вашего бота как **администратора** с полными правами (это обязательно для работы бота)
3. Получите ID канала (`TG_CHANNEL_ID`) — используйте любой Telegram-клиент или бота, который показывает ID чата (например, перешлите сообщение из канала боту [@userinfobot](https://t.me/userinfobot) или получите ID программно через Telethon). Скопируйте полученный числовой ID (например, `1234567890`) в `.env`
4. Отправьте в канал **два** сообщения в следующем порядке:
   - **Первое сообщение** (`TG_MEDIA_MESSAGE_ID`) — отправьте любое изображение **как сжатое фото** (а не как файл) и добавьте любой текст в качестве подписи. Например, можно отправить `default.png` из папки `session/spotify/`. Это сообщение будет использоваться для обложки альбома. Telegram Bot API позволяет заменять медиа только в сообщении, которое уже содержит изображение, поэтому обычное текстовое сообщение не подойдёт.
   - **Второе сообщение** (`TG_TEXT_MESSAGE_ID`) — отправьте любой текст. Это сообщение будет использоваться для отображения информации о треке.
5. Получите ID каждого сообщения — нажмите правой кнопкой мыши (или долгим нажатием) на сообщение и выберите «Копировать ссылку на сообщение». Ссылка выглядит как `https://t.me/имя_канала/123` — последнее число (`123`) — это ID сообщения. Скопируйте ID первого сообщения (с картинкой) в `TG_MEDIA_MESSAGE_ID`, а ID второго (с текстом) — в `TG_TEXT_MESSAGE_ID` в `.env`.

#### Сессии Telegram

SpotiPlayGram использует **две отдельные Telethon-сессии**:

- **User session** (`session/telegram/user.session*`) — требует полноценной авторизации в Telegram (номер телефона и облачный пароль, если он установлен). Используется для действий, где нужен реальный пользователь
- **Bot session** (`session/telegram/bot.session*`) — работает через `TG_BOT_TOKEN` и используется для панели управления (`/start`) и обновления канала

Для запуска на другом устройстве (ПК, сервер, VPS и т. д.) после первой авторизации скопируйте файлы `session/telegram/user.session*`, `session/telegram/bot.session*` и `session/spotify/.cache`.

Одновременно приложение может работать только на одном устройстве. При запуске оно проверяет метку в двух текстовых полях бота. Если приложение уже работает на другом устройстве, второе устройство покажет сообщение и не откроет Telegram-сессии, даже если файлы сессий и `.cache` уже скопированы. Если предыдущий запуск завершился аварийно, защита перестаёт действовать примерно через 90 секунд. Чтобы защита работала, хотя бы одно из двух полей — «Информация о боте» или «Описание» — должно быть свободно.

#### Метка блокировки в полях бота

У бота есть два текстовых поля:

- **«Информация о боте»** (`short_description`) — короткий текст под именем бота в профиле.
- **«Описание»** (`description`) — текст, который виден в чате с ботом до первого `/start`.

Пока приложение работает, в одном из этих полей находится служебная строка вида:

`SPG1|7f3a9c21|b4e8d0c6a2f1|5c1e9a7b3d2f4608a1c9e5b7|1735689600|1735689480`

Метка записывается в поле «Информация о боте», а поле «Описание» используется, только если в поле «Информация о боте» уже есть ваш текст. Это не пользовательский текст, а метка блокировки от одновременного запуска на нескольких устройствах. Если метка находится в поле «Информация о боте», она видна в профиле бота; если в поле «Описание» — в чате с ботом до первого `/start`. Расшифровка частей:

| Часть                        | Значение                                                              |
| ---------------------------- | --------------------------------------------------------------------- |
| `SPG1`                       | Версия формата метки                                                  |
| `7f3a9c21`                   | Идентификатор текущего запуска                                        |
| `b4e8d0c6a2f1`               | Идентификатор устройства (хеш)                                        |
| `5c1e9a7b3d2f4608a1c9e5b7`   | Идентификатор компьютера (хеш)                                        |
| `1735689600`                 | Время последнего heartbeat-сигнала (обновляется каждые 30 секунд)     |
| `1735689480`                 | Время запуска                                                         |

При штатном завершении приложение очищает поле. Если оно завершилось аварийно, метка остаётся, но через 90 секунд считается устаревшей, и следующий запуск сможет её перезаписать.

**Можно ли менять поля «Информация о боте» и «Описание», пока программа работает?**

Метка всегда находится только в одном из двух полей — «Информация о боте» или «Описание».

- Поле, в котором сейчас находится метка, менять нельзя: приложение проверяет его каждые 30 секунд и, обнаружив замену текста, завершает работу с предупреждением о потере блокировки. Если просто очистить поле, приложение вернёт метку при следующей проверке.
- Поле без метки менять можно: приложение только читает его и не изменяет.
- Если заполнить оба поля — «Информация о боте» и «Описание» — своим текстом, при следующем запуске приложение не сможет получить блокировку и продолжит работу без защиты от одновременного запуска на нескольких устройствах — в лог будет записано предупреждение.
- После остановки приложения поле с меткой очищается, и его можно менять свободно; при следующем запуске метка снова появится в поле «Информация о боте», а если оно занято — в поле «Описание».

### 📝 Настройка Genius (опционально)

1. Перейдите на [Genius API Clients](https://genius.com/api-clients)
2. Создайте новый API-клиент
3. Сгенерируйте токен доступа
4. Скопируйте токен в `.env`

### 🤖 Настройка Mistral AI (опционально)

1. Перейдите на [Mistral AI Console](https://console.mistral.ai)
2. Создайте API-ключ
3. Скопируйте ключ в `.env`

**Примечание о регистрации:** Регистрация в Mistral может потребовать номер телефона для верификации.

**Примечание о точности:** Без Mistral AI выбор ссылок на тексты песен на Genius будет менее точным. Встроенный алгоритм на основе Genius API хорошо работает в большинстве случаев, но в связке с Mistral AI точность значительно повышается.

**Примечание о кэшировании:** Mistral AI использует кэш результатов на 1 час для оптимизации производительности. Повторные запросы для одного трека будут обработаны мгновенно без дополнительных API-вызовов.

**Примечание о выборе модели:** Сравнить бенчмарки моделей Mistral можно на [Artificial Analysis](https://artificialanalysis.ai/providers/mistral), чтобы выбрать более точную модель для подбора лучшей ссылки на текст песни из результатов поиска Genius. Прежде чем выбрать модель, проверьте, сколько токенов в месяц доступно для этой модели. Месячные лимиты токенов для каждой модели можно посмотреть на странице [Mistral AI Limits](https://admin.mistral.ai/plateforme/limits). При обычном прослушивании музыки SpotiPlayGram тратит до 2 млн токенов в месяц. В худшем случае — при непрерывном прослушивании 24/7 и длительности треков не более 1 минуты — за месяц будет потрачено около 50 млн токенов. Фактический расход токенов можно посмотреть на странице [Mistral AI Usage](https://admin.mistral.ai/organization/usage?workspace_dialog_use_org_currency=false). Однако учитывайте, что самые умные и тяжёлые модели со временем могут начать возвращать ошибку **HTTP 429** из-за лимитов бесплатного тарифа — если это произойдёт, переключитесь на более лёгкую модель.

## ▶️ Запуск приложения

| Система               | Запуск               |
| --------------------- | -------------------- |
| Windows               | `python start.py`    |
| Linux, macOS, FreeBSD | `python3 start.py`   |

В Windows также можно запустить `start.py` двойным кликом или через контекстное меню «Открыть с помощью Python».

**Linux / FreeBSD (графическая среда / GUI):** Рекомендуется запускать приложение из обычной графической сессии (например, GNOME, KDE), потому что при первом запуске для авторизации Spotify должен открыться браузер.

**Linux / FreeBSD (подключение по SSH):** Для непрерывной работы при подключении через SSH используйте `screen` или `tmux`, чтобы приложение продолжало работать после отключения от сессии. На FreeBSD при необходимости установите их заранее: `pkg install screen` или `pkg install tmux`.

```bash
# Использование screen
screen -S SpotiPlayGram
python3 start.py
# Нажмите Ctrl+A, затем D для отсоединения
# Для переподключения: screen -r SpotiPlayGram

# Использование tmux
tmux new -s SpotiPlayGram
python3 start.py
# Нажмите Ctrl+B, затем D для отсоединения
# Для переподключения: tmux attach -t SpotiPlayGram
```

При первом запуске:

- Автоматически создастся виртуальное окружение.
- Установятся необходимые зависимости.
- Вам будет предложено авторизоваться в Telegram (вход по номеру телефона и облачному паролю, если он установлен).
- Вам будет предложено авторизоваться в Spotify (откроется браузер).

Автообновление зависимостей опционально и управляется через `ENABLE_DEP_UPDATES` в `.env`.

### 🔁 Автозапуск

`start.py` не включает и не выключает автозапуск. Это делают отдельные скрипты. Перед их использованием один раз запустите `start.py`, чтобы были созданы `venv` и зависимости.

**Включить и отключить**

| Система               | Включить                                      | Отключить                                      |
| --------------------- | --------------------------------------------- | ---------------------------------------------- |
| Windows               | `venv\Scripts\python.exe enable_autostart.py` | `venv\Scripts\python.exe disable_autostart.py` |
| Linux, macOS, FreeBSD | `venv/bin/python3 enable_autostart.py`        | `venv/bin/python3 disable_autostart.py`        |

Скрипты сами выбирают подходящий способ для системы. После выполнения они ждут Enter, чтобы консоль не закрылась. Для запуска без ожидания добавьте `--no-pause`.

**Проверить, включён ли автозапуск**

| Система | Проверка                                                                                                                                                                                                                   |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Windows | «Диспетчер задач» → «Автозагрузка» → строка `SpotiPlayGram` (проверьте, включён ли автозапуск). Или в командной строке: `dir "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\SpotiPlayGram.lnk"`                  |
| Linux   | `systemctl --user is-enabled spotiplaygram.service` (если включали скриптом) или `ls ~/.config/autostart/spotiplaygram.desktop` / `crontab -l` (если включали вручную)                                                     |
| macOS   | `ls ~/Library/LaunchAgents/com.spotisplaygram.plist` (`SpotiPlayGram` отображается в «Системных настройках» → «Объекты входа»)                                                                                             |
| FreeBSD | `ls ~/.config/autostart/spotiplaygram.desktop` или `crontab -l`                                                                                                                                                            |

Если строки или файла нет, автозапуск выключен.

## 🔄 Как это работает

1. **Цикл опроса:** Приложение опрашивает Spotify API каждую секунду (настраивается).
2. **Определение трека:** При обнаружении нового трека приложение получает полные метаданные.
3. **Поиск текста:** Ищет трек на Genius с помощью нечёткого сопоставления.
4. **AI-выбор:** Mistral AI выбирает наиболее точную ссылку на текст песни из результатов поиска Genius.
5. **Обновление Telegram:** Обновляет сообщения канала, его название и фото.
6. **Управление состоянием:** Сохраняет текущее состояние, чтобы избежать дублирования обновлений.

## 🛠️ Устранение неполадок

### 🎵 Spotify

**Ошибка авторизации / неверные учётные данные**

- Убедитесь, что `SPOTIFY_CLIENT_ID` и `SPOTIFY_CLIENT_SECRET` в `.env` совпадают с данными из [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).
- Проверьте, что `SPOTIFY_REDIRECT_URI` в `.env` точно совпадает с Redirect URI, указанным в настройках приложения на Dashboard (по умолчанию `http://127.0.0.1:47474/callback`).

**Токен Spotify истёк / не удаётся получить данные о воспроизведении**

- Удалите файл `session/spotify/.cache` и перезапустите приложение — авторизация будет выполнена заново в браузере.
- Проверьте, что приложение в Spotify Developer Dashboard не удалено и находится в активном состоянии.
- Если у вас бесплатный аккаунт Spotify, API для получения статуса воспроизведения может быть недоступен — требуется Premium.

### 📢 Telegram

**Ошибка авторизации / неверные учётные данные**

- Проверьте, что `TG_API_ID` и `TG_API_HASH` в `.env` совпадают с данными из [my.telegram.org](https://my.telegram.org).
- Убедитесь, что `TG_BOT_TOKEN` действителен — токен можно сгенерировать заново через [@BotFather](https://t.me/BotFather).

**Канал не обновляется**

- Убедитесь, что бот добавлен в канал как **администратор** с полными правами.
- Проверьте, что сообщения с ID `TG_MEDIA_MESSAGE_ID` и `TG_TEXT_MESSAGE_ID` действительно существуют в канале и не были удалены.
- Убедитесь, что `TG_CHANNEL_ID` указан верно (числовой ID канала, например, `1234567890`).

**Ошибки файлов сессии**

- Если приложение не может подключиться к Telegram или выдаёт ошибки сессии, удалите файлы `session/telegram/user.session*` и `session/telegram/bot.session*`, затем перезапустите приложение для повторной авторизации.
- Убедитесь, что другой экземпляр приложения не запущен одновременно — два процесса не могут использовать одну и ту же сессию.
- Если приложение уже запущено, повторный запуск покажет сообщение и будет ждать Enter, чтобы консоль не закрылась.

**Приложение завершается на втором устройстве**

- Одновременно может работать только одно устройство. Остановите приложение на устройстве, имя которого указано в сообщении, и нажмите Enter, чтобы закрыть консоль.
- После аварийного завершения защита снимается примерно через 90 секунд. На том же устройстве можно запустить приложение сразу.
- Для работы защиты хотя бы одно из двух полей — «Информация о боте» или «Описание» — должно быть свободно.

### 📝 Genius

**Поиск текстов песен не работает**

- Проверьте, что `GENIUS_ACCESS_TOKEN` в `.env` действителен — токен можно сгенерировать заново на странице [Genius API Clients](https://genius.com/api-clients).
- Убедитесь, что `ENABLE_GENIUS=True` в `.env`.

### 🤖 Mistral AI

**Mistral AI не отвечает / ошибки запросов**

- Проверьте, что `MISTRAL_API_KEY` в `.env` указан правильно и ключ активен в [Mistral AI Console](https://console.mistral.ai).
- Убедитесь, что `ENABLE_MISTRAL=True` в `.env`.
- Если модель возвращает ошибку, убедитесь, что она доступна — модели периодически обновляются и могут быть переименованы или удалены. Актуальный список моделей можно посмотреть через бота (⚙️ Genius settings → 🤖 Mistral AI models).
- При частых таймаутах попробуйте переключиться на более лёгкую модель (например, `ministral-3b-latest`).
